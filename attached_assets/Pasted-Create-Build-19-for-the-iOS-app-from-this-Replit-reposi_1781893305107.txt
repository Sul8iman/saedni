====================================================

1. HELPER PUSH NOTIFICATIONS
   ====================================================

Implement full Expo Push Notifications.

When a helper signs in:

* Request notification permission.
* Register Expo Push Token.
* Save/update Expo Push Token in the production database.

Each helper can enable notifications only once.

====================================================
2. SEND NOTIFICATION WHEN A NEW REQUEST IS CREATED
==================================================

Whenever a customer publishes a new request:

Send a push notification only to helpers that:

* are active
* helper role enabled
* notification permission granted
* have a valid Expo Push Token
* selected the request category
* selected the request location

Notification title:

طلب جديد متاح

Notification body example:

طلب جديد في بوشر
نقل وتحميل

Notification should include:

* Request ID
* Category
* Area

====================================================
3. NOTIFICATION ACTION
======================

When helper taps the notification:

Open the app directly.

If already logged in:

Navigate directly to:

الطلبات المتاحة

If not logged in:

Open login first, then continue to the available requests page.

====================================================
4. ADMIN OTP PUSH NOTIFICATIONS
===============================

Whenever any user requests a new OTP:

Create an Admin Notification immediately.

Requirements:

* unread counter updates
* notification appears instantly
* clicking notification opens the correct user profile
* if user does not yet exist, open fallback OTP details page
